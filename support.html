Besoin d’aide avec Reste. ?

Reste. est encore en développement. Cette page centralise les informations utiles pour les testeurs et futurs utilisateurs.

Un problème ou une suggestion ?

Sauvegarde et restauration

Conservez votre mot de passe de sauvegarde dans un endroit sûr. Reste. ne peut pas récupérer un mot de passe de sauvegarde oublié.

Données locales

Reste. fonctionne principalement avec les données enregistrées sur votre appareil. Avant de supprimer l’application ou de changer de téléphone, créez une sauvegarde si vous souhaitez conserver votre historique.

Version bêta

Une version TestFlight peut contenir des fonctions encore en validation. Si vous rencontrez un comportement étrange, indiquez si possible la version de l’application, le modèle de l’appareil et les étapes permettant de reproduire le problème.
