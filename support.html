AIDE & SUPPORT

Besoin d’aide avec U Restu ?

U Restu est encore en développement. Cette page centralise les informations utiles pour les testeurs et futurs utilisateurs.

Un problème ou une suggestion ?

Vous pouvez signaler un bug ou proposer une amélioration directement sur GitHub.

Ouvrir les issues d’U Restu →

Sauvegarde et restauration

Conservez votre mot de passe de sauvegarde dans un endroit sûr. U Restu ne peut pas récupérer un mot de passe de sauvegarde oublié.

Données locales

U Restu fonctionne principalement avec les données enregistrées sur votre appareil. Avant de supprimer l’application ou de changer de téléphone, créez une sauvegarde si vous souhaitez conserver votre historique.

Version bêta

Une version TestFlight peut contenir des fonctions encore en validation. Si vous rencontrez un comportement étrange, indiquez si possible la version de l’application, le modèle de l’appareil et les étapes permettant de reproduire le problème.

Confidentialité

Consultez la politique de confidentialité pour savoir comment U Restu traite vos données.
